Windows PowerShell: connect SSH and forward NoMachine. Keep this terminal open.
  ssh -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -L 14000:127.0.0.1:4000 -p 19422 airhust@airhust.cn

NoMachine: protocol NX, host 127.0.0.1, port 14000. Log in to the airhust desktop.

In the SSH terminal (or a terminal on the NoMachine desktop):
  cd /home/airhust/template2026_ws
  bash tools/start_sim.sh --gui
  bash tools/run_task.sh hover
Enter 1 to start. Any other input cancels. Startup checks connected MAVROS,
fresh odometry, 720-point scan and a running simulation clock. Task startup
refuses an armed simulator or an existing setpoint controller.

Stop and restart the simulator before each next task:
  bash tools/stop_sim.sh
  bash tools/start_sim.sh --gui
  bash tools/run_task.sh square

  bash tools/stop_sim.sh
  bash tools/start_sim.sh --gui
  bash tools/run_task.sh avoidance

Final cleanup:
  bash tools/stop_sim.sh

Equivalent direct roslaunch entry points:
  source tools/env.sh
  export DISPLAY="${DISPLAY:-:1001}"
  roslaunch -p 11411 simulation/sitl.launch gui:=true
The direct simulation entry runs in the foreground. In another SSH terminal:
  cd /home/airhust/template2026_ws
  source tools/env.sh
  roslaunch -p 11411 mission acceptance.launch task:=hover confirmed:=true
The confirmed:=true argument explicitly starts the task, including its automatic
OFFBOARD/arming flow. This direct form bypasses the shell confirmation and
preflight checks, so the run_task.sh form above is the normal acceptance entry.
For a directly launched simulator, Ctrl+C its foreground terminal to stop.
