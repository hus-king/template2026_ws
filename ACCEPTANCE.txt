See README.md for startup commands and editable parameters.
Set PX4_ROOT in tools/local.env to this computer's PX4 checkout.
The workspace path is detected automatically. For GUI mode, run from a graphical desktop terminal.
Start: bash tools/start_sim.sh --gui
Task:  bash tools/run_task.sh hover
Type 1 to begin. Replace hover with square or avoidance as needed.
Stop:  bash tools/stop_sim.sh
Restart the simulator before every next task.
Launch entries: simulation/sitl.launch and src/mission/launch/acceptance.launch.
Local logs: validation/runtime/sitl.log and validation/runtime/roslog/.
